How the Restock Logic Works

Printed Cups
Current stock comes from the client-specific Cup Stock tracker. Stock-out movements within 3 days are grouped as one order/release cycle so split releases do not artificially inflate frequency. If expectedWeeklyConsumption is already set, it is used as the planning rate; otherwise the dashboard learns from repeat release cycles.

Packaging
Current stock comes from general inventory. Consumption is learned from completed quotations using each product code. Products with only one historical completed order remain in Learning unless their physical stock is already at/below the inventory reorder level.

Reorder timing
Normal lead time is 7–10 days. This dashboard uses a 15-day safety window: when estimated stock cover reaches 15 days, status becomes Reorder Now. At 10 days or less it becomes Critical.

Suggested quantity
For repeat clients/products, the recommendation uses the typical order/release quantity and rounds packaging orders to the product's box size when available. This is a planning guide, not an automatic purchase order.
